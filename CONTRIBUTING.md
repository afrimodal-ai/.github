# Contributing

Thanks for your interest in AfriModal AI. These guidelines apply to every repository in the organization unless a repository has its own `CONTRIBUTING.md`.

## Issues

Open an issue for errors in code, data or documentation, for reproducibility problems, or to propose a change before starting substantial work. For a reproducibility problem, include the commit, the command you ran, your environment, and the output you got.

## Pull requests

Keep each pull request to one change. Describe what it changes and why, and how you checked it. Follow the existing style of the repository and update documentation when behaviour changes.

## Data contributions

Do not add speech, text or other data to a repository unless you have the right to share it under the repository's data licence, and speakers gave consent for that use. Never commit personal or identifying information about speakers or patients. If you are unsure, open an issue first and describe the data without attaching it.

## Licensing

Code, data, models and documentation may carry different licences. Check the licence files in each repository; by contributing, you agree that your contribution is released under the licence that applies to the part you changed.

## Conduct

All participation is covered by the [Code of Conduct](CODE_OF_CONDUCT.md).
