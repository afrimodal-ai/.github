# .github

Organization profile and default community health files for [AfriModal AI](https://github.com/afrimodal-ai).

- `profile/README.md` is shown on the organization page.
- `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` apply to any repository in the organization that does not have its own.

The Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org) 2.1 and, like the other text here, is available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
